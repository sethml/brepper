# Seeded randomized models (Phase 0.3)

Generated by `gen-test-models random` — see the "Randomized variants" section
of `src/bin/gen_test_models.rs`. Regenerate with:

```bash
cargo run --release --bin gen-test-models -- random tests/random 3 20260729
```

`params.tsv` records the seed and every drawn parameter (dimensions, radii,
tessellation deflection and angle, B-rep and mesh volume), so any surprising
row can be read and reproduced without re-deriving it.

## Why random

Fourteen hand-watched models can be satisfied by machinery that happens to fit
their particular radii and fillet sizes — and that is how the tuned-constant
pile grew. A seeded population cannot be memorized: its parameters land where
no constant was ever tuned. The five families deliberately sweep the
quantities the existing constants are sensitive to.

| family | what it sweeps | reference geometry |
|---|---|---|
| `rand_filleted_box` | fillet radius against face size — the ratio flat-region seeding is sensitive to (a blind 32-face patch straddles when flats are narrow) | 6 planes + 12 cylinders + 8 spheres |
| `rand_cone_chain` | 2–4 stacked frusta with independent half-angles: sharp rings where angles differ, tangent (invisible) joins where they nearly match | 2 planes + N cones |
| `rand_torus` | r/R from 0.08 to 0.85, deliberately **past `MAX_TORUS_RADIUS_RATIO` = 0.7** — a legitimately fat torus must not be rejected by a guard aimed at spurious fits | 1 torus |
| `rand_tube` | wall thickness down to where both cylinders' supports are narrow strips | 2 cylinders + 2 annular planes |
| `rand_ball_on_cylinder` | ball radius from 0.6× to 1.6× the post radius, so the junction ranges from a sharp ring to near-tangent | 1 sphere + 1 cylinder + 1 plane |

Mesh density is drawn independently of the geometry (deflection 0.02–0.4 mm,
angle 8–28°), so a model can arrive coarse *and* small-featured — the
combination the corpus never had.

Every model is validated at generation time: `BRepCheck` on the reference, and
the written STL is parsed back and checked as a closed oriented manifold with
its volume within 10% of the B-rep (a loose bound: it only catches a broken
mesh, since a coarse tessellation of a small-radius feature legitimately loses
a few percent).

## Status

These are harness models (`tools/sweep.sh`), not suite gates. The harness
sweeps them end to end with `--compare`; consult a current sweep row rather
than a status recorded here, which would go stale. The first sweep after
generation is the baseline the Phase 1 rework is measured against.
