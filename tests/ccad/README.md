# CodeCAD Test Models

Test models generated by [CodeCAD](https://codecad.xyz/). The generated STL/STEP
files are committed to the repo, so CodeCAD is not required to run tests.

## Regenerating Models

```bash
# Requires 'ccad' tool installed
./tests/ccad/generate_models.sh
```

This runs `ccad build` in the `tests/ccad/` directory and writes
STL + STEP pairs into `tests/ccad/generated/`.

## CodeCAD Primitive Conventions

Full documentation: `../codecad/docs/` (especially `core_primitives.md`,
`core_transform.md`, `core_boolean.md`).

**Critical: `box()` places a corner at the origin, NOT centered.**

| Primitive              | Placement                                  |
|------------------------|--------------------------------------------|
| `box(w, d, h)`         | Corner at origin, extends into +x/+y/+z   |
| `cylinder(diameter, h)` | Centered in x/y, z from 0 to h            |
| `sphere(diameter)`     | Centered at origin                         |
| `cone(d1, d2, h)`     | Centered in x/y, z from 0 to h            |
| `wedge(dx, dy, dz, ltx)` | Corner at origin                        |

To center a box at the origin, use `center_xyz(box(w, d, h))`.
Other centering helpers: `center_x()`, `center_y()`, `center_z()`,
`center_xy()`, `center_to(s, cx, cy, cz)`.

## Analytical Values

Every part's `.lua` file has comments near the top giving the expected
analytical surface area and volume. When writing tests or debugging surface
reconstruction, **use these values** from the lua file comments rather than
computing them from scratch.
