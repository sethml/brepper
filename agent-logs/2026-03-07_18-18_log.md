## 3. **STL Mesh Normals vs. STEP Surface Normals**

### **STL Mesh Face Normals** ([src/stage1.rs](src/stage1.rs#L479-L508))
- **Computed via:** Newell normal formula (robust for non-planar quads)
- **Stored in:** `MeshFace.normal: Option<[f64; 3]>`
- **Direction:** Determined by winding order (counter-clockwise when viewed from outside = outward)
- **Computed at:** Stage 1.2 validation phase

### **STEP Surface Normals**
- **Planar:** Normal = `gp::Dir` from `Geom_Plane::Direction()`; always points in construction direction
- **Cylindrical:** Normal points **radially away from axis** (outward) — per OCCT convention; tracked via `CylindricalHypothesis.convex` bool
- **Spherical:** Normal points **away from center** — per OCCT convention; tracked via `SphericalHypothesis.convex` bool

**Orientation Handling in Stage 3.4:** ([src/stage3.rs](src/stage3.rs#L1625-L1635))
```rust
let is_concave = match surface {
    SelectedSurface::Cylindrical(idx) => !output.stage2.cylindrical_hypotheses[*idx].convex,
    SelectedSurface::Spherical(idx) => !output.stage2.spherical_hypotheses[*idx].convex,
    _ => false,
};
// If convex=false, face orientation is REVERSED before passing to BRepBuilderAPI_MakeFace
```

## 4. **Hypothesis System: Associating STL Faces with STEP Surfaces**

### **BFS Region Growing** ([src/stage2.rs](src/stage2.rs#L250+))
Each hypothesis type (planar, cylindrical, spherical) uses identical BFS strategy:

1. **Seed:** For each unassigned mesh face with no hypothesis yet
2. **Fit surface:** Fit a geometric surface to the seed face
3. **Grow via BFS:** 
   - Add neighboring faces if they satisfy:
     - Normal alignment check (dihedral angle < `angular_tolerance_rad`, default 17.5°)
     - All vertices within `vertex_tolerance_mm` of fitted surface
   - Re-fit iteratively as new faces are added
4. **Store result:** Map mesh face → hypothesis index in `MeshFace.planar/cylindrical/spherical_hypothesis`

### **Selected Surfaces** ([src/stage2.rs](src/stage2.rs#L133-L142))
After all hypotheses deduced in stages 2.1-2.3:
- Stage 2.6 selects **one hypothesis per mesh face** and stores in `Stage2Output.selected_surfaces: Vec<SelectedSurface>`
- `SelectedSurface` enum: `Planar(usize) | Cylindrical(usize) | Spherical(usize)`
- Index refers into `planar_hypotheses`, `cylindrical_hypotheses`, or `spherical_hypotheses` vectors

### **Translation to OCCT** ([src/stage3.rs](src/stage3.rs#L309-L360))
- Build face descriptors with OCCT surface objects via `create_occt_surface()`
- For cylinders/spheres: Hypothesis `convex` bool determines if orientation needs reversal

    surface: &SelectedSurface,
    stage2: &Stage2Output,
    point: &[f64; 3],
) -> Option<[f64; 3]> {
    match surface {
        SelectedSurface::Planar(idx) => {
            let hyp = &stage2.planar_hypotheses[*idx];
            Some(hyp.normal)
        }
        SelectedSurface::Cylindrical(idx) => {
            let hyp = &stage2.cylindrical_hypotheses[*idx];
            // Project point onto the axis to find the closest axis point
            let ax = hyp.axis_direction;
            let ao = hyp.axis_origin;
            let dp = [
                point[0] - ao[0],
                point[1] - ao[1],
                point[2] - ao[2],
            ];
            let t = dp[0] * ax[0] + dp[1] * ax[1] + dp[2] * ax[2];
            let radial = [
                dp[0] - t * ax[0],
                dp[1] - t * ax[1],
                dp[2] - t * ax[2],
            ];
            let len = (radial[0] * radial[0] + radial[1] * radial[1] + radial[2] * radial[2]).sqrt();
            if len < 1e-15 {
                return None; // Point is on the axis
            }
            let mut n = [radial[0] / len, radial[1] / len, radial[2] / len];
            if !hyp.convex {
                n = [-n[0], -n[1], -n[2]];
            }
            Some(n)
        }
        SelectedSurface::Spherical(idx) => {
            let hyp = &stage2.spherical_hypotheses[*idx];
            let dp = [
                point[0] - hyp.center[0],
                point[1] - hyp.center[1],
                point[2] - hyp.center[2],

            let len = (dp[0] * dp[0] + dp[1] * dp[1] + dp[2] * dp[2]).sqrt();
            if len < 1e-15 {
