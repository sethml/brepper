The issue is on line 143: `tri_handle.get()` is called without checking if the handle is null first. `BRep_Tool::Triangulation` returns a null handle when a face has no triangulation (e.g. meshing failed for that face). The fix is to check `tri_handle.is_null()` before dereferencing.
