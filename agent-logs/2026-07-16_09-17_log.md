### Tolerance Settings

#### Surface Tolerance

This is how far the surface of a mesh triangle is allowed to deviate from the surface it is approximating.

Onshape calls this "Chordal tolerance (mm)", and the preset values are:
- Coarse: 0.24 mm
- Medium: 0.12 mm
- Fine: 0.06 mm

Fusion 360 calls this "Surface Deviation", and the preset values seem to vary based on model size:
- Low: 1x
- Medium: 2.5x
- High: 8x

#### Angular Tolerance

This is the maximum angle between adjacent triangle faces that approximate a smooth surface.

Onshape calls this "Angular deviation (deg)", and the present values are:
- Coarse: 12.5 deg
- Medium: 6.25 deg
- Fine: 2.5 deg

Fusion 360 calls this "Normal Deviation", and the preset values are:
- Low: 30.0
- Medium: 15.0
- High: 10.0
In theory "Normal Deviation" should be the maximum angular error of the face relative to the surface normal, but in practice it seems to result in the given maximum angular deviation.

fn compute_face_normal(face: &MeshFace, vertices: &[MeshVertex]) -> Option<[f64; 3]> {
    let vertex_count = face.vertex_count as usize;
    if !(3..=4).contains(&vertex_count) {
        return None;
    }

    // Newell normal handles both triangles and quads with consistent winding.
    let mut nx = 0.0_f64;
    let mut ny = 0.0_f64;
    let mut nz = 0.0_f64;

    for i in 0..vertex_count {
        let curr = vertices[face.vertex_indices[i]];
        let next = vertices[face.vertex_indices[(i + 1) % vertex_count]];

        nx += (curr.y - next.y) * (curr.z + next.z);
        ny += (curr.z - next.z) * (curr.x + next.x);
        nz += (curr.x - next.x) * (curr.y + next.y);
    }

    let len2 = nx * nx + ny * ny + nz * nz;
    if len2 <= 1.0e-24 {
        return None;
    }

    let inv_len = len2.sqrt().recip();
    Some([nx * inv_len, ny * inv_len, nz * inv_len])
}

/// Check whether the quad \`[v0, v1, v2, v3]\` is strictly convex, given the face normal.
fn is_convex_quad(vertices: &[MeshVertex], quad_verts: &[usize; 4], normal: &[f64; 3]) -> bool {
    for i in 0..4 {
        let v0 = &vertices[quad_verts[i]];
        let v1 = &vertices[quad_verts[(i + 1) % 4]];
        let v2 = &vertices[quad_verts[(i + 2) % 4]];

        let e1 = [v1.x - v0.x, v1.y - v0.y, v1.z - v0.z];
        let e2 = [v2.x - v1.x, v2.y - v1.y, v2.z - v1.z];

        // Cross product e1 × e2
        let cx = e1[1] * e2[2] - e1[2] * e2[1];
        let cy = e1[2] * e2[0] - e1[0] * e2[2];
        let cz = e1[0] * e2[1] - e1[1] * e2[0];

        // For convex quad, all cross products should agree with the normal direction
        let dot = cx * normal[0] + cy * normal[1] + cz * normal[2];

pub fn read_connected_mesh_from_stl(
    stl_path: &str,
    options: VertexWeldOptions,
) -> Result<ConnectedMesh, MeshReadError> {
    if !options.tolerance.is_finite() || options.tolerance <= 0.0 {
        return Err(MeshReadError::InvalidTolerance(options.tolerance));
    }

    if !std::path::Path::new(stl_path).exists() {
        return Err(MeshReadError::FileNotFound(stl_path.to_string()));
    }

    let progress = message::ProgressRange::new();
    let tri_handle = rw_stl::read_file_charptr_progressrange_2(stl_path, &progress);
    let tri = tri_handle.get();
    let num_nodes = tri.nb_nodes();
    let num_triangles = tri.nb_triangles();

    if num_nodes <= 0 || num_triangles <= 0 {
        return Err(MeshReadError::EmptyMesh);
    }

    let mut welder = VertexWelder::default();
    let mut node_to_welded_idx = vec![usize::MAX; (num_nodes as usize) + 1];
    let mut faces = Vec::with_capacity(num_triangles as usize);

    for tri_idx in 1..=num_triangles {
        let triangle = tri.triangle(tri_idx);

        let mut face_vertex_indices = [0_usize; 4];
        for (slot, fvi) in face_vertex_indices.iter_mut().take(3).enumerate() {
            let node_index = triangle.value((slot + 1) as i32);
            let node_slot = node_index as usize;

            let welded_idx = if node_to_welded_idx[node_slot] != usize::MAX {
                node_to_welded_idx[node_slot]
            } else {
                let node = tri.node(node_index);
                let v = MeshVertex::from_xyz(node.x(), node.y(), node.z());
                let idx = welder.get_or_insert(v, options.tolerance);
                node_to_welded_idx[node_slot] = idx;
                idx
            };

            *fvi = welded_idx;
        }

        faces.push(MeshFace {
            vertex_count: 3,
            vertex_indices: face_vertex_indices,
            neighbors: [-1, -1, -1, -1],
            normal: None,
            planar_hypothesis: UNDEDUCED_PLANAR_HYPOTHESIS,
            conical_hypothesis: UNDEDUCED_CONICAL_HYPOTHESIS,
            spherical_hypothesis: UNDEDUCED_SPHERICAL_HYPOTHESIS,
            toroidal_hypothesis: UNDEDUCED_TOROIDAL_HYPOTHESIS,
        });
    }

    Ok(ConnectedMesh {
        vertices: welder.vertices,
        faces,
        stats: MeshValidationStats::default(),
    })
}

impl ConnectedMesh {
    /// Repair degenerate triangles so validation can pass on real-world STL
    /// exports. Two defect classes are handled (both present in 3DBenchy.stl):
    ///
    /// 1. Triangles with repeated vertex indices (duplicate points collapsed
    ///    by vertex welding) — dropped; they contribute only a doubled edge.
    /// 2. Exactly-collinear zero-area slivers. These are usually T-junction
    ///    stitches: one side of the mesh has a long edge A–B, the other side
    ///    splits it as A–C, C–B, and the sliver A-B-C fills the crack.
    ///    Dropping the sliver alone would leave open edges, so the neighbor
    ///    face across the long edge A–B is split at C, restoring a closed
    ///    manifold. Chained slivers (one sliver stitching another sliver's
    ///    long edge) resolve iteratively: later splits target the faces
    ///    produced by earlier ones.
    ///
    /// Must run before quad fusion (stage 1.3): only triangles are repaired.
    pub fn repair_degenerate_faces(&mut self) -> MeshRepairStats {
        let mut stats = MeshRepairStats::default();
        let mut alive = vec![true; self.faces.len()];
        // Each removed sliver requests a split of its long edge at the
        // vertex opposite it (for exactly-collinear points, that vertex lies
        // between the long edge's endpoints).
        let mut pending_splits: Vec<(EdgeKey, usize)> = Vec::new();

        for (face_idx, face) in self.faces.iter().enumerate() {
            if face.vertex_count != 3 {
                continue;
            }
            let [a, b, c, _] = face.vertex_indices;
            if a == b || b == c || a == c {
                alive[face_idx] = false;
                stats.faces_dropped_duplicate_vertex += 1;
                continue;
            }
            if compute_face_normal(face, &self.vertices).is_some() {
                continue;
            }
            alive[face_idx] = false;
            stats.faces_dropped_sliver += 1;
            let d2 = |p: usize, q: usize| {
                let (vp, vq) = (self.vertices[p], self.vertices[q]);
                let (dx, dy, dz) = (vp.x - vq.x, vp.y - vq.y, vp.z - vq.z);
                dx * dx + dy * dy + dz * dz
            };
            let (p, q, interior) = [(a, b, c), (b, c, a), (c, a, b)]
                .into_iter()
                .max_by(|x, y| d2(x.0, x.1).total_cmp(&d2(y.0, y.1)))
                .unwrap();
            pending_splits.push((EdgeKey::new(p, q), interior));
        }

        if !stats.repaired_anything() {
            return stats;
        }

        // Edge → face lookup over surviving faces, extended as splits create
        // new faces. Dead faces are filtered at lookup time.
        let mut edge_map: HashMap<EdgeKey, Vec<usize>> = HashMap::new();
        let mut register_face_edges =
            |face: &MeshFace, face_idx: usize, edge_map: &mut HashMap<EdgeKey, Vec<usize>>| {
                let vc = face.vertex_count as usize;
                for i in 0..vc {
                    let key = EdgeKey::new(
                        face.vertex_indices[i],
                        face.vertex_indices[(i + 1) % vc],
                    );
                    edge_map.entry(key).or_default().push(face_idx);
                }
            };
        for (face_idx, face) in self.faces.iter().enumerate() {
            if alive[face_idx] {
                register_face_edges(face, face_idx, &mut edge_map);
            }
        }

        // A split may only become possible after another split has produced
        // its target face (chained slivers), so retry until no progress.
        loop {
            let mut unresolved = Vec::new();
            let mut progress = false;

            for (edge, interior) in pending_splits {
                let targets: Vec<usize> = edge_map
                    .get(&edge)
                    .into_iter()
                    .flatten()
                    .copied()
                    .filter(|&f| alive[f] && self.faces[f].vertex_count == 3)
                    .collect();
                if targets.is_empty() {
                    unresolved.push((edge, interior));
                    continue;
                }

                for t in targets {
                    // Split triangle (u, v, w) with u→v on the long edge into
                    // (u, c, w) and (c, v, w); winding is preserved.
                    let tri = self.faces[t].clone();
                    let i = (0..3)
                        .find(|&i| {
                            EdgeKey::new(tri.vertex_indices[i], tri.vertex_indices[(i + 1) % 3])
                                == edge
                        })
                        .expect("edge_map entry must correspond to a face edge");
                    let (u, v, w) = (
                        tri.vertex_indices[i],
                        tri.vertex_indices[(i + 1) % 3],
                        tri.vertex_indices[(i + 2) % 3],
                    );
                    alive[t] = false;
                    for child_indices in [[u, interior, w, 0], [interior, v, w, 0]] {
                        let child = MeshFace {
                            vertex_count: 3,
                            vertex_indices: child_indices,
                            neighbors: [-1, -1, -1, -1],
                            normal: None,
                            planar_hypothesis: UNDEDUCED_PLANAR_HYPOTHESIS,
                            conical_hypothesis: UNDEDUCED_CONICAL_HYPOTHESIS,
                            spherical_hypothesis: UNDEDUCED_SPHERICAL_HYPOTHESIS,
                            toroidal_hypothesis: UNDEDUCED_TOROIDAL_HYPOTHESIS,
                        };
                        let child_idx = self.faces.len();
                        register_face_edges(&child, child_idx, &mut edge_map);
                        self.faces.push(child);
                        alive.push(true);
                    }
                    stats.faces_split += 1;
                }
                progress = true;
            }

            if unresolved.is_empty() || !progress {
                stats.splits_unresolved = unresolved.len();
                break;
            }
            pending_splits = unresolved;
        }

        let mut keep = alive.into_iter();
        self.faces.retain(|_| keep.next().unwrap());
        stats
    }
}

## Standard mesh-repair operations in the wild

Yes — there's a well-established canon. The main reference implementations are **admesh** (the classic STL fixer, used inside Slic3r/PrusaSlicer as `stl_fix`), **Cura/libArcus**, **netfabb** (now Autodesk, long the industry standard), **Microsoft's 3MF repair service** (the "3D Builder" fixer Windows ships), **Meshmixer's Inspector**, **trimesh**/**MeshLab** in the open-source tooling world, and **CGAL's Polygon Mesh Processing** package on the algorithmic side. They converge on roughly the same pipeline, ordered from cheap/safe to invasive:

1. **Vertex welding** with exact or tolerance hashing — brepper already does this (stage 1.1).
2. **Degenerate facet removal** — zero-area and duplicate-vertex triangles — brepper now does this.
3. **T-junction stitching** — what we just built. (admesh doesn't do this; netfabb and CGAL's `stitch_borders`/autorefine family do.)
4. **Normal/winding unification** (admesh `--fix-normals`): BFS across shared edges, flipping faces so all windings agree, then orient the whole shell by signed volume. Deterministic and geometry-preserving.
5. **Crack stitching / gap closing** (netfabb "stitch triangles", trimesh `stitch`, CGAL `stitch_borders`): pair up near-coincident open boundary edges, optionally re-welding with a progressively larger tolerance. Fixes hairline cracks from CAD exports where facets along a shared edge disagree at the 1e-6 level — one of the most common defects in "messy but printable" files.
6. **Duplicate/coincident face removal**: exact duplicates, and back-to-back opposite-winding pairs (internal walls) — the usual cause of non-manifold edges in booleaned or assembled models.
7. **Small hole filling** (admesh `--fill-holes`, netfabb, Meshmixer): triangulate open boundary loops — ear-clipping or minimal-area patch for small loops.
8. **Non-manifold edge/vertex splitting**: where >2 faces meet an edge, split into manifold sheets or delete interior partition walls.
9. **Debris removal**: delete disconnected shells below a face-count/volume threshold, or "keep largest shell".
10. **Self-intersection resolution**: boolean-union overlapping shells (Cura's "union overlapping volumes", winding-number methods à la libigl). Slicers can often skip this because slicing itself uses even-odd/winding rules per layer.
11. **Voxel/winding-number remesh** ("make solid") — the nuclear option; guaranteed watertight but discards the original facets entirely.

## Which make sense for brepper

Brepper's constraint is unusual: repairs must **preserve the original facet geometry exactly**, because stage 2 fits analytic surfaces to it. That rules out remeshing (11) and makes hole filling (7) risky beyond trivial cases. Ranked by payoff-per-risk:

| Priority | Operation | Why for brepper |
|---|---|---|
| High | Winding unification + shell orientation flip (4) | Currently hard errors (`InconsistentOrientation`, `InvertedNormals`). Zero geometric change — just flips. Straightforward with the edge map we already build. |
| High | Coincident-face removal (6) | Turns many `NonManifoldEdges` failures into clean meshes; exact, no geometry change. |
| Medium | Boundary crack stitching (5) | Very common in CAD exports; a targeted re-weld of open-edge endpoints at a slightly larger tolerance (bounded by `vertex_tolerance`) is safe and cheap. |
| Medium | Debris-shell removal (9) | Trivial to add since shells are already computed; probably best gated by a size threshold and reported loudly. |
| Lower | Non-manifold splitting (8) | Valuable but genuinely hard to do right; ambiguous topology. |
| Lower | Small hole filling (7) | Only where the loop is small relative to `surface_tolerance` (e.g., pinholes), since invented facets will be fitted. |
| Skip | Self-intersection booleans, remeshing (10, 11) | Destroys the geometry brepper exists to preserve. |

**What was implemented:**

- **Coincident-face removal** (`repair_coincident_faces`): triangles over the same three vertices are grouped and classified by winding. Opposite-winding pairs — internal walls left by booleans or assembled solids — cancel and both are removed; same-winding duplicates reduce to a single face. Both forms previously guaranteed a `NonManifoldEdges` hard error.
- **Winding unification** (`repair_winding`): BFS propagates orientation across manifold edges within each shell (two faces agree when they traverse a shared edge in opposite directions) and flips the minority class; components with contradictory parity (non-orientable) are left untouched for validation to report. Then whole closed shells with negative signed volume are flipped, unless they're voids bbox-contained in a positive closed shell — the same rule validation uses, now sharing a `face_signed_volume_contribution` helper instead of duplicated cross-product code.
