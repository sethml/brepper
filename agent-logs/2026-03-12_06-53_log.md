- **`fillet_all(s, r)`** — Rounds all edges with radius `r`
- **`chamfer_all(s, d)`** — Chamfers all edges with distance `d`

**Selective edge control** (filter then apply):
1. `edges(shape)` → `EdgeQuery`
2. Chain filters: `on_box_side(side)`, `geom("line"|"circle")`, `parallel(axis, tol_deg?)`, `dihedral_between(min, max)`, `length_between(min, max)`
3. `.collect()` → `EdgeSet`
4. Pass to `fillet` or `chamfer`

## 2. CodeCAD Revolve Operations (`core_construction.md`)

**`revolve(profile, angle_deg)`** — Revolves a profile (drawn in XZ plane via `profile_xz`) around the Z-axis.
- `angle_deg` 0–360 (partial revolves supported)
- Open profiles → lathe-like surfaces; closed profiles → solid disks
- Profile touching Z-axis at both ends → sealed solid

**`profile_xz(pts, closed?)`** — Builds polyline on XZ plane (Y=0) for revolve input.

## core_features.md (complete)

```
# Features

Features let you add finishing touches to your parts by softening or beveling sharp edges. CodeCAD provides both global (all edges) and selective (filtered edges) variants for fillets and chamfers.

## Global Edge Modifiers

### fillet_all(s, r)
Applies a rounded fillet of constant radius r to all eligible edges of a shape.

### chamfer_all(s, d)
Applies a straight chamfer of distance d to all eligible edges of a shape.

## Selective Edge Control

### Edge Query Workflow
1. Start with edges(shape) to create an EdgeQuery.
2. Apply filters such as on_box_side, geom, parallel, dihedral_between, length_between.
3. Collect results with .collect().
4. Pass the resulting EdgeSet into fillet or chamfer.

### Edge Filters
- on_box_side(side) — Valid values: xmin, xmax, ymin, ymax, zmin, zmax
- geom(kind) — line (straight) or circle (arcs)
- parallel(axis, tol_deg?) — x, y, or z within tolerance (default 3°)
- dihedral_between(min_deg, max_deg) — angle between adjacent faces
- length_between(min_mm, max_mm) — edge length interval
```

Here's a comprehensive summary of what CodeCAD offers (and doesn't offer):

## What CodeCAD has for 2D profiles / sketches

| Method | Description |
|--------|-------------|
| `poly_xy(pts)` | Polygonal face on XY plane from point list (straight-edge segments only) |
| `profile_xz(pts, closed?)` | Polyline on XZ plane from point list (straight-edge segments only) |
| `rect(w, h)` | Axis-aligned rectangle on XY plane |

## What CodeCAD has for construction (2D → 3D)

| Method | Description |
|--------|-------------|
| `extrude(face, height)` | Linear extrusion along +Z |
| `revolve(profile, angle_deg)` | Revolve an XZ profile around Z-axis |
| `lathe(opts)` | Higher-level revolve with thickness/hollowing options (uses XZ control points) |
| `curved_plate_xy(...)` | BSpline-based doubly-curved plate |

## What CodeCAD has for primitives

`box`, `cylinder`, `sphere`, `cone`, `wedge`, `hex_prism`, `poisson_plate`

---

## What's **missing** (your questions):

1. **2D circular arc or circle profile** — **Not available.** All sketch/profile tools (`poly_xy`, `profile_xz`, `rect`) produce only straight-line segments. There is no `arc()`, `circle()`, `circle_xy()`, or spline-based 2D curve primitive. The word "circle" only appears in the edge filter context (`geom("circle")` for selecting existing circular edges) and in the gear terminology glossary.

2. **Torus primitive** — **Not available.** There is no `torus()` function. The word "torus" does not appear anywhere in the docs.

3. **Revolving a circular cross-section** — **Not possible with native profiles.** Since `profile_xz` and `lathe` both take polyline control points (straight segments between points), revolving them always creates conical/planar strips, never a true toroidal surface. You could approximate a circle with many polygon points, but it would produce flat faceted strips on revolution, not an actual `Geom_ToroidalSurface`.

4. **Profile construction beyond `profile_xz`** — Only `poly_xy` and `rect` exist as alternatives. No arc segments, spline segments, or fillet-within-profile tools are documented.

**Bottom line:** CodeCAD cannot produce a true torus or any geometry with toroidal surfaces. All profiles are piecewise-linear, so revolving them yields conical/planar faces rather than true circular cross-sections. To test torus recognition in brepper, you'd need to create the STEP file via another tool (FreeCAD, OpenSCAD+OCCT, or direct OCCT API).
