/// Rejects a degenerate giant-radius cylinder, cone, or sphere. A small patch
/// of a gently curved surface barely constrains its own radius, so an
/// underdetermined fit commits an absurd one and still validates at vertex
/// tolerance: on `part_rounded_cube` coarse each 3-face corner blend — truly
/// the r = 2 corner sphere — fits an r ≈ 32 cylinder on a 10 mm part and
/// reconstructs 0.39 mm off. A surface belonging to the model must fit inside
/// it, so a radius past the mesh bounding-box diagonal is degenerate by
/// construction. This is the same guard `torus_candidate` already applies to a
/// torus's major radius, extended to the other analytic types.
fn radius_plausible(mesh: &ConnectedMesh, hyp: &CompeteHyp, bb_diag: f64) -> bool {
    match hyp {
        CompeteHyp::Conical(h) => conical_local_radius(mesh, h) <= bb_diag,
        CompeteHyp::Spherical(h) => h.radius <= bb_diag,
        // Planes have no radius; tori are guarded in `torus_candidate`.
        CompeteHyp::Planar(_) | CompeteHyp::Toroidal(_) => true,
    }
}
