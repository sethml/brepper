### Key Patterns

- **Planar** is the simplest: 2-DOF (normal + distance), single-face seeds, no convexity, no angular coverage check.
- **Spherical** uses 4-DOF algebraic fit, 1-ring seeds, convexity via radial-normal dot, solid-angle coverage check (eigenvalue ratio).
- **Conical** uses 6-DOF (apex + axis + half_angle), apex-vertex seeding with eigenvalue non-coplanarity test, LM refinement, convexity, azimuthal angular coverage.
- **Toroidal** is the heaviest: 7-DOF, dual fitting strategies (medial axis + SOR), 1-ring seeds excluding other committed surfaces, convexity relative to tube center, both azimuthal AND minor-circle angular coverage.
- All non-planar surfaces track `convex: Option<bool>` — set from the first face after seed fit, then enforced during BFS expansion.
- None of the four types currently override `centroid_distance`, `seed_vtol_multiplier`, or `angular_tol_multiplier` (despite the trait docs suggesting cones should).
