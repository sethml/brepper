I dug into the actual assembly to ground this rather than reason from the smell. Here's what I found and what I'd do.

What the architecture actually is
Stage 3 already builds edges once as shared TopoDS_Edge objects (indexed by edge id, reused across both adjacent faces' wires). So it's not naïvely rebuilding edges per face. But the final assembly is BRepBuilderAPI_Sewing — a geometric stitch that re-merges edges by proximity/tolerance — not a topological assembly that trusts the shared edges. Sewing is load-bearing because:

MakeFace/MakeWire/ShapeFix copy edges, so "shared" edges stop being identical objects after face construction.
The UV-bounds faces (spheres, tori, full-revolution cones — and my attempted cap) generate their own natural-bounds boundary edges that are genuinely not shared with neighbors. Sewing is the reconciliation layer that papers over the two construction paths.
The face-construction + sewing block is ~2100 lines with 152 pole/seam/apex/ShapeFix/reorient/degenerate/sewing special-cases. That is the real signal: this is where complexity accumulates, and it's the common root of the cone-apex bug and the tangent-edge tolerance relaxations ("ambiguous junction rows" are geometric-matching slop).

Is the narrow patch the right fix? No — and it probably can't fully work alone.
My cap attempt half-worked precisely because the problem spans layers: segmentation → edge topology (are edges 0/4 the same arc or complementary?) → face trimming (pie-slice-with-apex) → sewing. Patching only the face-construction layer left the boundary not matching neighbors. A wire-based cap with a degenerate apex edge might close it, but it'd be one more bespoke case bolted onto the 152 that already exist.

Is a rework the right answer? Yes — but not now, and not for this model.
The principled design is a shared-edge topological assembler: build each edge once, attach a pcurve on both adjacent faces, insert degenerate/seam edges uniformly for every periodic surface, then assemble the shell directly with BRep_Builder — no geometric sewing. That dissolves the whole class: cone apex, sphere pole, torus seam, and the tangent-edge tolerance relaxations all become "attach the correct pcurve to the shared edge."

But three things say not yet:

Reward/risk is upside-down today. 52/57 pass. The only beneficiary right now is one unusual model that already emits valid-ish output with a volume warning. A 2000-line rewrite risks the 52 for that.
The payoff is unlocked by NURBS, the deferred project-defining feature. Freeform surfaces have arbitrary trimmed boundaries and will hammer exactly this machinery; building NURBS on top of projection+sewing is building on sand. The rework is the right foundation to lay when NURBS starts — and that's also when there'll finally be test coverage to validate a more-general assembler (today I'd be generalizing a machine tested only on analytic surfaces it already handles).
No forcing function yet. Every current model is either passing or a documented low-value warning. Nothing is blocked by the sewing fragility.
Recommendation
Do neither now. Leave cone_tangent_planes as a known warning (its TODO already has the sharp diagnosis). Record an explicit architectural decision: the edge-generation + sewing rework is bound to the NURBS effort — it's the foundation for it, pays for itself there, and gets test coverage there. The trigger to pull it forward earlier is if a model becomes unfixable without tighter topology (i.e., the tangent-edge relaxations start failing real models rather than just loosening tolerances).

## Visualization (`--viz-stages`)
The `--viz-stages` flag enables interactive 3D visualization for debugging each pipeline stage. The user specifies a stage pattern (e.g. `2.2` for conical BFS, or `2.*` for all stage 2 sub-stages). The companion `--viz-stages-level` flag (default 1) controls how often the visualization pauses: level 1 pauses at committed hypotheses and stage 2.6 selections, level 2 also pauses at each accepted seed, and level 3 also pauses at each individual BFS face acceptance.
### Architecture
The visualization uses a two-thread architecture with synchronous channel communication:
1. **Main thread**: Owns the window, drives the three-d render loop, and displays overlays.
2. **Pipeline thread**: Runs the brepper pipeline (stages 1–4) in the background.

Pipeline thread                          Main/render thread
     │                                         │
     │  VizOverlay (via SyncSender)             │
     ├────────────────────────────────────────►  │
     │                                         │ display overlay, wait for keypress
     │  VizAction (via SyncSender)              │
     │  ◄────────────────────────────────────────┤
     │                                         │
     ▼                                         ▼

#### 3.x (proposed) Rework: shared-edge topological assembly instead of geometric sewing

**Status: not started. Deliberately deferred and bound to the NURBS effort (see Future Enhancements). This section records the decision and its trigger so it is not rediscovered from scratch.**

**The current design.** Stage 3.4 builds each face independently and stage 3.5 reconciles them with `BRepBuilderAPI_Sewing`, a *geometric* stitch that merges edges by proximity within a tolerance. Edges *are* created once as shared `TopoDS_Edge` objects (§3.1), but two things defeat that sharing by assembly time:
- `MakeFace`/`MakeWire`/`ShapeFix` copy edges, so the "shared" edge in face A is no longer the identical object in face B.
- The UV-bounds construction paths (full spheres, complete tori, full-revolution and — as of the cone-cap investigation — apex-cap cones) synthesize their *own* natural-bounds boundary edges that were never shared with a neighbour at all.

So sewing is load-bearing, and the `ReconEdge.pcurves: [_; 2]` and `BRepVertex.uv_coords` fields (§3.0) that the original design earmarked for a both-sides-shared representation were never populated — the geometric sewing pass stands in for them. The face-construction + sewing block is ~2100 lines carrying ~150 pole/seam/apex/reorient/ShapeFix/degenerate special-cases.

1. Build each edge once (shared `TopoDS_Edge` + shared vertices, with its 3D curve) — as today.
2. For **both** adjacent faces of every edge, compute and attach the pcurve of that edge on that face's surface (populate `ReconEdge.pcurves`). Poles/seams are handled *only* here, in pcurve computation, uniformly for every periodic surface.
3. Insert degenerate edges at UV poles (cone apex, sphere pole) and seam edges at periodic wraps, shared correctly, as first-class topology rather than per-surface fix-ups.
4. Assemble each face and the shell directly with `BRep_Builder` from the shared edges — the shell is closed *by construction*. Drop `BRepBuilderAPI_Sewing`; it becomes at most a validation check.
5. This makes construction lower-level and more controlled (avoid `ShapeFix`/`MakeFace` edge-copying that breaks sharing). **Why defer it.** 52/57 models pass; nothing is *blocked*. The only current beneficiary is one unusual model (`cone_tangent_planes`) that already writes valid-ish output with a volume warning. def _vscode_data_dirs() -> list[str]:
    """Return candidate VS Code user-data directories, ordered by preference.

    Checks TERM_PROGRAM_VERSION to prefer Insiders when running inside it.
    Supports macOS, Linux, and Windows.
    """
    variants = ["Code - Insiders", "Code"] if _force_insiders else ["Code", "Code - Insiders"]

    platform = sys.platform
    dirs: list[str] = []
    for variant in variants:
        if platform == "darwin":
            base = os.path.expanduser(f"~/Library/Application Support/{variant}")
        elif platform == "win32":
            appdata = os.environ.get("APPDATA", "")
            base = os.path.join(appdata, variant) if appdata else ""
        else:  # linux / other unix
            config = os.environ.get("XDG_CONFIG_HOME", os.path.expanduser("~/.config"))
            base = os.path.join(config, variant)
        if base:
            dirs.append(base)
    return dirs


def find_workspace_storage(workspace_path: str) -> list[str]:
    """Find VS Code workspace storage dirs for the given workspace.

    Returns all matching storage directories.  A directory can match via the
    ``folder`` key (regular folder workspace) or via the ``workspace`` key
    (multi-root ``.code-workspace`` file located inside *workspace_path*).
    """
    abs_path: str = os.path.abspath(workspace_path)
    folder_uri: str = "file://" + abs_path

    # Collect .code-workspace URIs for files in the directory
    workspace_file_uris: set[str] = set()
    for name in glob.glob(os.path.join(abs_path, "*.code-workspace")):
        workspace_file_uris.add("file://" + name)

    results: list[str] = []
    for data_dir in _vscode_data_dirs():
        ws_storage = os.path.join(data_dir, "User", "workspaceStorage")
        if not os.path.isdir(ws_storage):
            continue
        for entry in os.listdir(ws_storage):
            ws_json = os.path.join(ws_storage, entry, "workspace.json")
            if os.path.isfile(ws_json):
                try:
                    with open(ws_json) as f:
                        data = json.load(f)
                    stored_folder: str = unquote(data.get("folder", "")).rstrip("/")
                    stored_workspace: str = unquote(data.get("workspace", "")).rstrip("/")
                    if stored_folder and stored_folder == folder_uri.rstrip("/"):
                        results.append(os.path.join(ws_storage, entry))
                    elif stored_workspace and stored_workspace in workspace_file_uris:
                        results.append(os.path.join(ws_storage, entry))
                except (json.JSONDecodeError, IOError):
                    continue
    return results


def get_session_index(storage_path: str) -> dict[str, Any] | None:
    """Read the chat session index from the SQLite state DB."""
    db_path = os.path.join(storage_path, "state.vscdb")
    conn = sqlite3.connect(f"file:{db_path}?mode=ro", uri=True)
    try:
        cursor = conn.execute(
            "SELECT value FROM ItemTable WHERE key = 'chat.ChatSessionStore.index'"
        )
        row = cursor.fetchone()
        return json.loads(row[0]) if row else None
    finally:
        conn.close()

def replay_jsonl(filepath: str) -> dict[str, Any]:
    """Replay the JSONL to reconstruct the full session state."""
    session_state: dict[str, Any] = {}
    requests_by_id: dict[str, dict[str, Any]] = {}
    request_order: list[str] = []
    response_windows: dict[str, list[tuple[int, list[dict[str, Any]]]]] = {}   # rid -> list of (seq, window) pairs
    # Track sequence numbers for interjection detection
    seq = 0
    request_submit_seq: dict[str, int] = {}   # rid -> seq when request was submitted
    # Track which request IDs came from the initial kind:0 snapshot
    # (used to detect forked sessions — forks embed parent requests in the snapshot)
    initial_snapshot_rids: set[str] = set()
    # Track result/modelState/followups writes with their seq and origin index
    result_writes: list[tuple[int, int, dict[str, Any]]] = []        # list of (seq, idx, value)
    model_state_writes: list[tuple[int, int, Any]] = []   # list of (seq, idx, value)
    followups_writes: list[tuple[int, int, Any]] = []     # list of (seq, idx, value)

        for line in f:
            line = line.strip()
            if not line:

def humanize_model_id(model_id: str) -> str:
    """Convert a model ID like 'copilot/claude-opus-4.6' to 'Claude Opus 4.6'."""
    if not model_id:
        return ""
    # Strip provider prefix
    name = model_id.split("/")[-1] if "/" in model_id else model_id
    if name == "auto":
        return "Auto"
    # Capitalize each part: claude-opus-4.6 -> Claude Opus 4.6
    parts = name.split("-")
    result: list[str] = []
    for part in parts:
        # Keep version numbers as-is
        if re.match(r'^\d', part):
            result.append(part)
        else:
            result.append(part.capitalize())
    return " ".join(result)


def sanitize_for_markdown(text: str) -> str:
    """Ensure code fences in text are balanced so they don't break the document."""
    lines = text.rstrip().split("\n")
    fence_count = 0
    for line in lines:
        stripped = line.strip()
        if re.match(r'^`{3,}', stripped):
            fence_count += 1
    if fence_count % 2 != 0:
        # Remove the trailing unmatched fence
        for i in range(len(lines) - 1, -1, -1):
            if re.match(r'^`{3,}', lines[i].strip()):
                lines.pop(i)
                break
    return "\n".join(lines)


def fence_for(content: str) -> str:
    """Return a backtick fence string long enough that content can't close it."""

    return '`' * max(3, max_run + 1)
